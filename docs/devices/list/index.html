List devices

List all devices on your account.

GET https://api.whatspie.com/devices

Send your API token in the Authorization: Bearer YOUR_API_TOKEN header. See Authentication.

Request example​

curl -L -X GET 'https://api.whatspie.com/devices' \
  -H 'Accept: application/json; charset=utf-8' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'

Device fields​

FieldTypeDescription
idintegerDevice ID. Use it in /devices/{id}.
phonestring or nullThe device's WhatsApp number. null until the device is connected. Use it as device when sending messages.
webhook_urlstring or nullURL that receives webhooks.
statusstringDevice status, ACTIVE by default.
versionstringDevice version label.
paired_statusstringPAIRED (connected to WhatsApp) or UNPAIRED. See Paired status values.
device_name_mobilestring or nullDevice name.
node_urlstring or nullInternal connection server URL.
image_urlstring or nullProfile picture URL.
notify_is_connectedbooleanNotification setting for connect events.
notify_is_disconnectedbooleanNotification setting for disconnect events.
notify_updatesbooleanNotification setting for updates.
is_store_incoming_messagebooleanWhether incoming messages are stored in Whatspie.
is_proxy_enablebooleanWhether the connection uses a proxy.
created_at, updated_atstringTimestamps, ISO 8601.
serverobjectConnection server: name, status.
packageobjectPackage: code, name.
subscriptionobjectMessage quota: quote_available (-1 means unlimited) and quote_used, both strings. The API spells these fields quote; they mean quota.

Paired status values​

paired_statusDescription
UNPAIREDNot connected to WhatsApp. Scan the QR code to connect.
PAIREDConnected to WhatsApp and ready to send.

A device changes back to UNPAIRED when its WhatsApp session ends, for example when it is logged out from the phone.

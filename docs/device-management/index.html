Device management

A device is one WhatsApp number connected to Whatspie. Every message you send goes through a device. These endpoints create, list, update, and delete devices, and return the QR code that connects a device to WhatsApp.

Connect your first device​

You need a connected device before you can send messages. Follow these steps once per WhatsApp number.

  1. Get your API token. See Authentication.

  2. Add a device. In the Whatspie dashboard, open Devices in the sidebar and click Add Device. Enter a Device Name, choose a package, and click Create Device.

    Packages come in Free and Paid plans with different features. Compare them on the pricing page before you choose.

    Just trying Whatspie? Choose a package marked Free in the Add Device form. You can add a paid device later.

    Reseller accounts can also use Create device from code.

  3. Find the device. It now appears in Devices in the dashboard. From code, call List devices and note the device's id. A new device has paired_status: "UNPAIRED", which means it is not connected to WhatsApp yet. Its phone is still empty (null) until you scan the QR code.

  4. Scan the QR code. In Devices, click Connect next to your device to show its QR code. Then scan it with your phone: open WhatsApp, go to Linked devices, and tap Link a device. You have about 20 seconds.

    Use the API only if your own app must show the QR code, for example to your customers: call Get QR code with that id.

  5. Check that it is connected. In Devices, the device's Status column shows that it is connected, and its WhatsApp number appears. From code, call Get device every few seconds until paired_status is PAIRED; its phone field then holds the WhatsApp number.

Use that phone number as device when you send messages.

Two device identifiers
  • id (a number, for example 5) goes in the URL of device endpoints: /devices/{id}.
  • phone (for example 6281234567890) goes in the device field when you send messages.

Base URL​

https://api.whatspie.com

Authentication​

All device endpoints need your API token:

Authorization: Bearer YOUR_API_TOKEN

See Authentication.

Device operations overview​

OperationMethodEndpointDescription
Create devicePOST/devicesCreate a new device on a package. Reseller accounts only (accounts that resell Whatspie devices); others use the dashboard.
List devicesGET/devicesAll devices on your account.
Get deviceGET/devices/{id}One device.
Get QR codeGET/devices/{id}/qrQR code to connect the device to WhatsApp.
Update devicePUT/devices/{id}Change the phone number, status, or webhook URL. See the warning before using it.
Delete deviceDELETE/devices/{id}Delete a device.

{id} is the numeric device id from List devices, not the phone number.

Package selection examples​

# Create device with Starter package
curl -L -X POST 'https://api.whatspie.com/devices' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  --data-raw '{
    "package": "STARTER60K",
    "name": "Basic Bot"
  }'

# Create device with Business package

  }'

Best practices​

Device creation​

  1. Meaningful names: use descriptive names so devices are easy to tell apart.
  2. Package selection: choose a package that fits your message volume.
  3. Monitoring: watch the connection of critical devices, for example with the device_disconnected webhook.

QR code management​

  1. Secure display: show QR codes only to the person who owns the phone. Anyone who scans it controls the device.
  2. Expiry handling: the QR code expires after about 20 seconds; ask for a new one if needed.
  3. Auto-refresh: while waiting for a scan, request a new QR code when the old one expires.

Connection monitoring​

  1. Regular checks: during connection, check paired_status with Get device every 3–5 seconds until it is PAIRED.
  2. Timeout handling: stop after a reasonable time and show the user a fresh QR code.
  3. Error recovery: retry failed QR requests.

Send video message

Send a video from a public URL to a phone number, with an optional caption. The recipient can play it inline in WhatsApp.

Videos use type: "file" with a params.video object. In Whatspie, type is a label for the message; what WhatsApp receives is decided by params. With params.video the recipient gets a playable video, while params.document (see Send file) would deliver the same file as a document.

Endpoint​

POST https://api.whatspie.com/messages

Send your API token in the Authorization: Bearer YOUR_API_TOKEN header. See Authentication.

Request​

ParameterTypeRequiredDescription
devicestringYesPhone number of your sending device: the phone field from List devices, not the numeric device id.
receiverstringYesRecipient's phone number. Up to 35 characters.
typestringYesfile. There is no video type; it is rejected with 400.
paramsobjectYesMessage content.
params.video.urlstringYesDirect, public URL of the video file.
params.mimetypestringNo, recommendedVideo MIME type, for example video/mp4. See Common video MIME types.
params.captionstringNoCaption shown under the video. Supports WhatsApp formatting.

Write phone numbers in international format without +. See Phone number format.

params accepts only these keys: text, caption, fileName, mimetype, location, image, document, video. Any other key, such as viewOnce, is rejected with 400.

Videos have no legacy format. A top-level file_url field sends the file as a document, not as a playable video.

Supported video formats​

The API does not download or check the video when it accepts your request. WhatsApp applies its own limits when the video is delivered:

FormatNotes
MP4Most compatible format.
MOVApple QuickTime.
AVIWindows format.
WebMModern web format.

Common video MIME types​

FormatMIME typeExtension
MP4video/mp4.mp4
MOVvideo/quicktime.mov
AVIvideo/x-msvideo.avi
WebMvideo/webm.webm
MKVvideo/x-matroska.mkv

Video requirements​

  • Maximum file size: 64 MB.
  • Recommended duration: up to 90 seconds for reliable delivery.
  • Accessibility: the URL must be public and point directly to the video file.
  • Processing: WhatsApp may compress the video when it is delivered.

Examples​

Basic video message​

curl -X POST 'https://api.whatspie.com/messages' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d '{
    "device": "6281234567890",
    "receiver": "6289876543210",
    "type": "file",
    "params": {
      "video": {
        "url": "https://example.com/videos/demo.mp4"
      },
      "mimetype": "video/mp4",
      "caption": "Check out this amazing video! 🎥✨"
    }
  }'

In these examples, 6281234567890 is your device (the phone from List devices) and 6289876543210 is the receiver. Replace both with your own numbers.

Video with a formatted caption​

curl -X POST 'https://api.whatspie.com/messages' \

  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d '{
    "device": "6281234567890",
    "receiver": "6289876543210",
    "type": "file",
    "params": {
      "video": {
        "url": "https://example.com/videos/product-demo.mp4"
      },
      "mimetype": "video/mp4",
      "caption": "🎉 *NEW PRODUCT DEMO* 🎉\n\n_Watch our latest innovation in action_\n\n✅ Easy to Use\n✅ Powerful Features\n✅ Lightning Fast\n\n*Available Now!*\n\nOrder today: https://shop.example.com"
    }
  }'

Video without a caption​

curl -X POST 'https://api.whatspie.com/messages' \

      "video": {
        "url": "https://example.com/videos/tutorial.mp4"
      },
      "mimetype": "video/mp4"
    }
  }'

Response​

A successful request returns HTTP 200 with the queued message. The fields are the same as for text messages. For a video:

  • type is file.
  • body holds the caption, or an empty string without one.
  • params holds the video URL, MIME type, and caption.
  • file_url, file_name, and file_mime are null.

Errors​

{
  "status": 400,
  "message": "Invalid message type. Must be one of: chat, image, file, location, template, list"
}
HTTP statusmessageCause
400Invalid message type. Must be one of: ...type is video or another unsupported value. Use file.
400Invalid message params: ...params contains a key that is not allowed, or video is not an object with only url.
400Invalid request body: ...The body is not valid JSON, or device, receiver, or type is missing.
403Missing Authorization header, Missing token in Authorization header, Invalid Authentication TokenToken problem. See Authentication.
403Device not found or access denieddevice is not a device on your account.
403Quota or subscription messageYour package has no messages left.
500Error descriptionInternal error, for example the message could not be saved. Try again later.

The API accepts the message first and sends it in the background. Problems with the video, such as a dead link or a file that is too large, and sending failures, such as a disconnected device or a number that is not on WhatsApp, do not cause an error response. They show up later as status ERROR with a failed_reason. Check them with Get message; see Status values.

Code examples​

JavaScript helpers, validation, batch sending, retries, and use cases for video messages are in the Messaging guide.

Limitations​

  • File size: up to 64 MB per video (WhatsApp limit).
  • Duration: up to 90 seconds is recommended for reliable delivery.
  • Formats: MP4, MOV, AVI, WebM (WhatsApp limit).
  • URL: must be public and direct. The API does not check it; see Errors.
  • Sending rate: space out your messages to avoid WhatsApp blocks.
  • Compression: WhatsApp may compress large videos.

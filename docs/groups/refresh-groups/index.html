Refresh groups

Fetch a device's current group list from its live WhatsApp connection and save it in Whatspie. List groups and Get group read this stored list, so refresh it after you join, leave, or change a group.

Endpoint​

POST https://api.whatspie.com/groups/refresh

Send your API token in the Authorization: Bearer YOUR_API_TOKEN header. See Authentication.

Query parameters​

ParameterTypeRequiredDescription
devicestringYesPhone number of the device whose groups to refresh.

Request example​

curl -X POST 'https://api.whatspie.com/groups/refresh?device=6281234567890' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Accept: application/json'

Response fields​

Same shape as List groups; see that page for each field. data holds only the groups synced by this call. updated_at is the time of this refresh for every synced group.

Errors​

HTTP statusmessageCause
400Device parameter is requiredThe device query parameter is missing.
403Device not found or access denieddevice is not a device on your account.
403failed to fetch group list from whatspie node: ... containing Disconnected or Connection issueThe device is not connected to WhatsApp, or Whatspie could not reach it.
403Missing Authorization header, Missing token in Authorization header, Invalid Authentication TokenToken problem. See Authentication.

Missing device parameter​

{
  "status": 400,
  "message": "Device parameter is required"
}

Device not found or access denied​

{
  "status": 403,
  "message": "Device not found or access denied"
}

Device disconnected​

{
  "status": 403,
  "message": "failed to fetch group list from whatspie node: Disconnected"
}

The device must be connected (paired and online), because the group list is fetched live from its WhatsApp connection.

How it works​

  1. Whatspie fetches the current group list from the device's live WhatsApp connection.
  2. Each group is upserted into the stored list, matched by device and group JID: existing groups are updated in place, newly joined groups are added.
  3. Groups you have left on WhatsApp are not removed from the stored list.
  4. Title, picture, mute, and spam status are updated from WhatsApp. The stored description is cleared to null on every refresh; see the warning below.
Descriptions are cleared

A refresh currently sets description to null for every synced group, even if the group has a description on WhatsApp.

When to use this

Call this endpoint after joining a new group, or periodically if you rely on List groups for up-to-date group data and don't want to wait for the next automatic sync.

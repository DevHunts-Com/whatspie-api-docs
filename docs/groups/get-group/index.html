Get group

Get the details of one group by its ID. The response has the same fields as each entry in List groups: name, description, picture, and status.

The data comes from the groups Whatspie has stored for your devices. It does not include the group's members, admins, permissions, or message history.

Endpoint​

GET https://api.whatspie.com/groups/{id}

Send your API token in the Authorization: Bearer YOUR_API_TOKEN header. See Authentication.

Path parameters​

ParameterTypeRequiredDescription
idintegerYesThe group's id from List groups, for example 15378. Not the jid; see Which ID to use.

Request example​

curl -L -X GET 'https://api.whatspie.com/groups/15378' \
  -H 'Accept: application/json; charset=utf-8' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'

Response​

{
  "status": 200,
  "message": "OK",
  "data": {
    "id": "15378",
    "device_id": "5",
    "jid": "120363022368688477@g.us",
    "title": "Project Team Alpha",
    "description": "Development team for Project Alpha - Sprint planning and daily updates",
    "image_url": "https://example.com/group-avatar-482.jpg",
    "muted": false,
    "spam": false,
    "group_created_at": "2024-11-15T09:00:00Z",
    "created_at": "2024-11-15T09:05:00Z",
    "updated_at": "2024-12-20T14:30:00Z"
  }
}

Response fields​

FieldTypeDescription
idstringWhatspie's ID for the group.
device_idstringID of the device that is in this group.
jidstringWhatsApp's group identifier, ending in @g.us.
titlestringGroup name.
descriptionstring or nullGroup description. Currently set to null by every Refresh groups run.
image_urlstring or nullGroup picture URL.
mutedbooleanWhether the group is muted on your device.
spambooleanWhether the group is marked as spam.
group_created_atstringWhen the group was created on WhatsApp, ISO 8601.
created_atstringWhen Whatspie first stored the group for your device, ISO 8601.
updated_atstringWhen the stored group information last changed, ISO 8601.

To get the latest name or picture from WhatsApp, run Refresh groups first. Note that a refresh currently clears description to null.

Errors​

HTTP statusmessageCause
400Invalid group IDid is not a number, for example a jid.
404Group not foundNo group with this id, or it belongs to a device on another account.
403Missing Authorization header, Missing token in Authorization header, Invalid Authentication TokenToken problem. See Authentication.
401User not authenticatedInternal authentication error. A missing or wrong token normally returns 403 first.

Usage examples​

Get group details with error handling​

async function getGroupDetails(token, groupId) {
  const response = await fetch(`https://api.whatspie.com/groups/${groupId}`, {
    headers: {
      Accept: 'application/json; charset=utf-8',
      Authorization: `Bearer ${token}`,
    },
  });

  const result = await response.json();
  if (!response.ok) {
    throw new Error(`${result.status}: ${result.message}`);
  }

  const group = result.data;
  console.log(`Group: ${group.title}`);
  console.log(`JID: ${group.jid}`);
  console.log(`Description: ${group.description ?? '(none)'}`);
  console.log(`Muted: ${group.muted ? 'Yes' : 'No'}`);
  return group;
}

getGroupDetails('YOUR_API_TOKEN', 15378)
  .then(() => console.log('Group loaded successfully'))
  .catch((error) => console.error('Failed to load group:', error.message));

Export group report​

async function exportGroupReport(token, groupId) {
  const group = await getGroupDetails(token, groupId);

  const report = {
    name: group.title,
    jid: group.jid,
    description: group.description,
    hasPicture: Boolean(group.image_url),
    muted: group.muted,
    spam: group.spam,
    createdOnWhatsApp: new Date(group.group_created_at).toLocaleDateString(),
    firstStored: new Date(group.created_at).toLocaleDateString(),
    lastUpdated: new Date(group.updated_at).toLocaleDateString(),
  };

  console.log(`📋 GROUP REPORT: ${report.name}`);
  console.log('='.repeat(50));
  console.log(`🆔 JID: ${report.jid}`);
  console.log(`📝 Description: ${report.description ?? '(none)'}`);
  console.log(`🖼️ Picture: ${report.hasPicture ? 'Yes' : 'No'}`);
  console.log(`🔕 Muted: ${report.muted ? 'Yes' : 'No'}`);
  console.log(`📅 Created on WhatsApp: ${report.createdOnWhatsApp}`);
  console.log(`📅 Last updated: ${report.lastUpdated}`);

  return report;
}
